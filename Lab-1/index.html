Part 1: System Architecture

Below is a basic description of the 8-bit system that we will utilize for the lab. There are two important components you need to understand:

  • Registers: Registers are small storage locations that each hold an 8-bit value, such as 00110011. This system has 4 registers. They are selected using a 2-bit register ID:
    • Register ID 00
    • Register ID 01
    • Register ID 10
    • Register ID 11

  • Memory: Memory is a larger storage area than registers. Some instructions may read from memory or write to memory. In this simplified system, memory access is controlled by a single "memory access" bit within each instruction.

Instruction Format

Every instruction is exactly 8 bits and is formatted like this:

[3-bit instruction] [1-bit memory access] [2-bit source register 1] [2-bit source register 2]

We will write these fields as:

iii m s1 s2

  • iii = the 3-bit instruction code (which operation to perform)
  • m = the 1-bit memory access flag
    • m = 1 means: this instruction is allowed to perform a memory read/write (required for load/store)
    • m = 0 means: this instruction does not use memory (recommended for non-memory operations)
  • s1 = 2-bit register ID for source register 1
  • s2 = 2-bit register ID for source register 2

Commands

This system supports 8 operations (because 3 bits can represent 8 distinct instruction codes). The table below defines the instruction codes we will use in this lab:

Instruction Code (iii) Name When is m required? What it does
000 IN (Read Input) m = 0 (memory not used) Read a value from input into register s1. (s2 ignored.)
001 OUT (Write Output) m = 0 (memory not used) Write the contents of register 01 (Register #1) to output. (s1 and s2 ignored.)
010 LOAD m = 1 required Load from memory address indicated by s1 into register s2.
011 STORE m = 1 required Store the value in register s1 into memory address indicated by s2.
100 ADD m = 0 (memory not used) Add registers s1 and s2, store the result back into s1: s1 = s1 + s2.
101 SUB m = 0 (memory not used) Subtract registers s1 and s2, store the result back into s1: s1 = s1 - s2.
110 AND m = 0 (memory not used) Bitwise AND of s1 and s2, store back into s1: s1 = s1 AND s2.
111 OR m = 0 (memory not used) Bitwise OR of s1 and s2, store back into s1: s1 = s1 OR s2.

Important notes about the memory-access bit (m):

  • For LOAD and STORE, you must set m = 1 (otherwise the instruction should be considered invalid for this lab).
  • For all other instructions, you should use m = 0. (If m is set to 1 accidentally, it is "don’t care" for this lab unless your instructor specifies otherwise.)

Instruction Examples

Below are example instructions, shown in binary and broken into their fields (iii)(m)(s1)(s2):

  • 0000 10 00   (000)(0)(10)(00): Read input into register 10.
  • 0010 00 00   (001)(0)(00)(00): Write register 01 (Register #1) to output. (Both register fields ignored.)
  • 0101 00 11   (010)(1)(00)(11): LOAD from memory address indicated by register 00 into register 11.
  • 0111 10 01   (011)(1)(10)(01): STORE the value in register 10 into the memory address indicated by register 01.
  • 1000 11 00   (100)(0)(11)(00): ADD: R11 = R11 + R00.
  • 1100 01 11   (110)(0)(01)(11): AND: R01 = R01 AND R11.

Special Behavior

This simplified system has one special behavior used throughout the lab:

  • OUT always outputs Register 01: The OUT instruction ignores s1 and s2 and always writes the contents of register 01 to output.

Program 1: Add Two Inputs, Output the Sum

This program reads two values from input, adds them, and outputs the result. Assume the first input goes into register 10 and the second input goes into register 11. Then we compute R10 = R10 + R11, copy the result into R01, and output it.

Note: Since OUT only outputs R01, we need to move the computed result into R01. We do not have a dedicated MOV instruction, so we use:

  • Clear R01 by doing R01 = R01 - R01
  • Add the value we want into R01 (e.g., R01 = R01 + R10)

Step English Description Binary Instruction
1 IN: Read input into register 10 Q9: __________

4 SUB: Clear register 01 by doing R01 = R01 - R01 Q12: __________
5 ADD: Copy sum into R01 by doing R01 = R01 + R10 Q13: __________
6 OUT: Write register 01 to output Q14: __________

  • Q15: Which register holds the final sum right after Step 3? Which register holds the final sum right after Step 5?
