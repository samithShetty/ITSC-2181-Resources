Part 1: System Architecture

Below is a basic description of the 8-bit system that we will utilize for the lab. There are two important components you need to understand:

  • Registers: Registers are small storage locations that each hold an 8-bit value, such as 00110011. This system has 4 registers, numbered 0-3.

  • Memory: Memory is a larger storage area than registers. Some instructions may read from memory or write to memory. In this simplified system, memory access is controlled by a single "memory access" bit within each instruction.

Instruction Format

Every instruction is exactly 8 bits and is formatted like this:

[3-bit instruction] [1-bit memory access] [2-bit source register 1] [2-bit source register 2]

We will write these fields as:

iii m s1 s2

  • iii = the 3-bit instruction code (which operation to perform)
  • m = the 1-bit memory access flag
    • m = 1 means: this instruction is allowed to perform a memory read/write
    • m = 0 means: this instruction only uses registers
  • s1 = 2-bit register ID for source register 1
  • s2 = 2-bit register ID for source register 2

Commands

This system supports 8 operations (because 3 bits can represent 8 distinct instruction codes). The table below defines the instruction codes we will use in this lab:

System Instruction Codes, Names, and Functionality
Instruction Code (iii) Name What it does
000 IN (Read Input) Read a value from input into register s1. (s2 ignored.)
001 OUT (Write Output) Write the contents of register 01 (Register #1) to output. (s1 and s2 ignored.)
010 LOAD Load from memory address indicated by s1 into register s2.
011 STORE Store the value in register s1 into memory address indicated by s2.
100 ADD Add registers s1 and s2, store the result back into s1: s1 = s1 + s2.
101 SUB Subtract registers s1 and s2, store the result back into s1: s1 = s1 - s2.
110 AND Bitwise AND of s1 and s2, store back into s1: s1 = s1 AND s2.
111 OR Bitwise OR of s1 and s2, store back into s1: s1 = s1 OR s2.

Important notes about the memory-access bit (m):

  • For LOAD and STORE, you must set m = 1
  • For all other instructions, you should use m = 0.

Instruction Examples

Below are example instructions, shown in binary and broken into their fields (iii)(m)(s1)(s2):

  • 00001000   (000)(0)(10)(00): Read input into register 10.
  • 00100000   (001)(0)(00)(00): Write register 01 (Register #1) to output. (Both register fields ignored.)
  • 01010011   (010)(1)(00)(11): LOAD from memory address indicated by register 00 into register 11.
  • 01111001   (011)(1)(10)(01): STORE the value in register 10 into the memory address indicated by register 01.
  • 10001100   (100)(0)(11)(00): ADD: R11 = R11 + R00.
  • 11000111   (110)(0)(01)(11): AND: R01 = R01 AND R11.
