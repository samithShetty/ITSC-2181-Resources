Module 1 Lab: Translating Computer Instructions

This lab covers the following course topics:

  • Understanding of the basic function of a Von-Neumann architecture.
  • Conversion of decimal values to binary values, and the reverse.
  • Conversion of binary values into hexidecimal values, and the reverse.
  • Translation of binary values to basic computing instructions, and the reverse.

Lab Description

You'll do this by translating the basic commands, which are described below, into the corresponding binary values, which is what the system would actually utilize. Part 1: System Architecture

Below is a basic description of the 8-bit system that we will utilize for the lab. There is two important components you need to understand:

  • Registers: Registers are basic areas in which we can store 8-bit values, such as "00110011". This system has 8 registers. These slots are ordered, counted from 0 to 7, and their position (register number) can be represented with a 3-bit value, like "011".

Commands

Now that we understand the basic definitions of these components, we can talk about how to use them. There are four basic things this system can do, which are defined below. In each definition, there will be some components inside of brackets, such as "[rs1]". This represents a place that different values could be placed, which change How the actual commands will execute. If the letters inside of brackets start with "rs" (such as "[rs2]"), this represents a place to put a register's 3-bit register number. If the letters inside of the brackets start with "ma" (such as "[ma]"), this represents a place to put a memory slot's 6-bit slot number.

  • Add Two Registers (Code: 00[rs1][rs2]): This function adds the value in [rs1] to the value stored in Register #1 (001), and stores the resulting value in [rs2].

  • Subtract Two Registers (Code: 01[rs1][rs2]): This function subtracts the value in [rs1] from the value stored in Register #1 (001), and stores the resulting value in [rs2].

  • Bitwise Logical AND Two Registers (Code: 10[rs1][rs2]): This function applies bitwise logical AND to the values in [rs1] and Register #1 (001), and stores the resulting value in [rs2].

  • Bitwise Logical OR Two Registers (Code: 11[rs1][rs2]): This function applies bitwise logical OR to the values in [rs1] and Register #1 (001), and stores the resulting value in [rs2].

Instruction Examples

Below are some utilizations of the the instructions above, with descriptions:

  • 00001101 (00)(001)(101): Add Register #1 to Register #1, store in Register #5
  • 01011110 (01)(011)(110): Subtract Register #3 from Register #1, store in Register #6
  • 10010100 (10)(010)(100): Apply Logical AND to Reigsters #2 and #1, store in Register #4
  • 11000111 (11)(000)(111): Apply Logical OR to Reigsters #0 and #1, store in Register #7

Special Registers

There are two special registers in this system, which have special functions:

  • Register #0 (000): Register #0 is special as it always holds the value 0 (00000000). It cannot be saved over, and will always have this value.
  • Register #1 (001): Register #1 is special as it always the second register used in any command. You can save over it, or otherwise use it, as you would any other register, but it will always be used in all commands.
