Project 1: Convolution in RISC-V Assembly

This project covers the practical application of the following concepts in RISC-V assembly:

  • Understanding the load-pattern of RISC-V Assembly
  • Register manipulation and data loading/storing with arrays.
  • Control flow with loops and branching.
  • Translating high-level algorithms to assembly language.

Project Description

In this project, you will implement a simple 1-D convolution on an array of integers. You will first develop the algorithm in a high-level programming language of your choice, and then translate it to RISC-V assembly, and finally provide a write-up explaining your implementation.

Algorithm Overview

First, here is the basic pseudocode outline of the convolution algorithm you will implement:


A = {[initial array values]}    // Input array of fixed size N, initialized to random values
B = {0,0,0,...}                 // Output array of fixed size N, initialized to zeros

for i from 0 to N-1 do:
    sum = A[i]
    if i > 0 then:
        sum = sum + A[i-1]      // Add left neighbor if it exists
    if i < N-1 then:
        sum = sum + A[i+1]      // Add right neighbor if it exists
    B[i] = sum / 3              // Each element in B is just the average of the corresponsing element in A and its neighbors
            
Print Array_A                   // Output the original array
Print Array_B                   // Output the convolved array

This program ultimately "smooths out" the values in the input array by averaging each element with its immediate neighbors.
Notice how since the first and last elements are each missing a neighbor, we have to check before we try accessing the data before/after the current element in the array.

Examples

  • [4, 2, 8, 7, 3, 9, 1, 6]       ---> [2, 4, 5, 6, 6, 4, 5, 2]
  • [1, 1, 1, 1, 1]                ---> [0, 1, 1, 1, 0]
  • [180, 54, 70, 32, 100, 4, 90]  ---> [78, 101, 52, 67, 45, 64, 31]

Part 1: High-Level Implementation

Implement the convolution algorithm in a high-level language of your choice (e.g., C, Python, Java). Your code should:

  • Define input array A and output array B.
  • Use a loop to compute the convolution for each element in the array.
  • Handle edge cases (e.g. the first and last elements).
  • Print the input and output arrays for verification.

Part 2: RISC-V Assembly Implementation

Translate your high-level algorithm into RISC-V assembly. Your assembly program should:

  • Initialize the input and output arrays in memory.
  • Implement a loop using branching instructions
  • Sum and take the average for each index with its neighbors (Note: You are allowed to use the div pseudo-instruction for this Project).
  • Use branching instructions to handle the edge-cases.
  • Store results in the output array.

Part 3: Write-Up

Write a short explanation (1-2 paragraphs) covering:

  • Your algorithm design, including how you are handling edge cases.
  • Key differences between the high-level and assembly implementations.
  • Any challenges faced during translation and how you addressed them.

Submission Format

For this project, you will submit a single document (Word or PDF) containing:

  • Your complete high-level code.
  • Your complete RISC-V assembly code.
  • Screenshots of at least three (3) successful test runs with different input arrays (showing input, output, and any intermediate steps).
  • Your 1-2 paragraph write-up explaining the code and design decisions.
