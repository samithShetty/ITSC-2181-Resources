Module 2 Lab: RISC-V Assembly Programming in RARS

This lab covers the following course topics and goals:

  • Practice reading documentation to understand software behavior
  • Understanding the structure and execution flow of RISC-V assembly programs.
  • Proficiency with arithmetic and logic instructions (add, sub, addi, slli, srli, srai, and, or, xor).
  • Proficiency with loading and storing data from memory using lw and sw instructions.
  • Understanding bit-manipulations for numeric operations.

Lab Description

In this lab, you will write RISC-V assembly programs using RARS. You will start by understanding an existing Hello World program, then progress through increasingly complex operations: arithmetic and logic instructions, memory access with variables and arrays, and finally character manipulation.

  • You will gain hands-on experience with how high-level code translates to assembly instructions.
  • You will understand the practical constraints and capabilities of low-level operations.
  • You will practice the workflow of writing, testing, and debugging assembly code.

Each program should be clearly commented and submitted with answers to all conceptual questions.

Submission Format

For this lab, you will submit a single document (.txt, .pdf, or Word) containing:

  • Your answers to all conceptual questions, labeled by part and question number (e.g., "Part 2.1 Q1")
  • Screenshots of successfully executed assembly code

Part 1: Introduction to RARS and Hello World

In this part, you will set up RARS, learn the basic structure of a full RISC-V assembly program, and run a basic Hello World program.

Setup and Tutorial

Follow these steps to get started:

  • Tutorial: This video provides a walkthrough the RARS repo and documentation, as well as downloading and running RARS
  • Download RARS: Go to https://github.com/TheThirdOne/rars and scroll down to the Download section of the README . Install the appropriate version for your operating system.
  • Read the Hello World Tutorial: Read through the Hello World tutorial to get an idea of what a full RISC-V program looks like. Make sure to read the code comments to understand what each line is doing
  • Copy and Execute: Copy the final Hello World program into RARS and execute it. Verify that the output appears in the console.
  • Extra Research: Take a closer look at the documentation shown in the walkthrough video and read through the Fundamentals of RISC-V Assembly to learn more!

Part 2: ALU Instructions (Arithmetic and Logic)

In this part, you will write programs using arithmetic and logic instructions to perform mathematical and bitwise operations.

Program 2.1: Arithmetic Operations

Write a program that computes: x = ((y - z) / 2) * 17, where:

  • x is stored in register t0 (the final result)
  • y is stored in register t1 with initial value 12
  • z is stored in register t2 with initial value 20

After computing the result, print the value of x to the console. (Hint: use ecall with a7 = 1 to print an integer.)

Program 2.1 Skeleton:

.text
    .globl main

main:
    # TODO: Initialize registers

    # TODO: Compute x

    # Print x
    addi a0, t0, 0    # Move x into a0 for printing
    addi a7, x0, 1    # System call for print integer
    ecall

    # Exit
    addi a7, x0, 10
    ecall

Part 2.1 Conceptual Questions:

Q2.1.1: What RISC-V instruction(s) did you use to divide by 2 and why? What would happen if you used the alternative instruction? Q2.1.2: What RISC-V instruction(s) did you use to multiply by 17? Explain how the math works out.

After computing the result, print the value of z to the console.

Part 3: Loading and Storing (Memory Access)

In this part, you will work with variables and arrays in memory, using lw (load word) and sw (store word) instructions.

Program 3.1: Load, Compute, and Store Variables

Write a program that:

  • Declares variables x = 21, y = 81, and z (uninitialized) in the .data section
  • Loads x and y from memory into registers

Part 4: Challenge - Character Indexing and Printing

This is a challenge problem that combines memory access, dynamic indexing, and character I/O.

Write a program that:

  • Declares a string with your name in the .data section (e.g., .asciz "Alice")
  • Declares a variable i = 4 (the index to access)
  • Loads the index from memory
  • Loads the character at position name[i] from the string
  • Prints that character to the console

Hint: Unlike words (4 bytes each), characters are single bytes. You will need to use lb (load byte) instead of lw (load word). To print a character, use ecall with a7 = 11. See the RARS ecall reference for details.

    # Exit
    addi a7, x0, 10

Part 4.1 Conceptual Questions:

Q4.1.1: Why do you use lb (load byte) instead of lw (load word) to load a character from the string? What is the difference between the two instructions in terms of how many bytes they read from memory?

Q4.1.2: When accessing elements of a word array, you multiply the index by 4 (because each word is 4 bytes). For character arrays (strings), do you need to multiply by anything? Why or why not?

Q4.1.3: What character was printed by your program? Verify that it is the correct character from your name at index 4.

Q4.1.4 (Bonus): What would happen if you set i = 0? What character would be printed? What if you set i to a value larger than the length of your name? Why might this be dangerous?
