Part 3: Writing C Code

For this component of the lab, you'll be re-implementing the convolution function from Project 1, this time writing the code using C. Use this same pseudocode from before as reference for what you need to implement: 


        A = {[initial array values]}    // Input array of fixed size N, initialized to random values
        B = {0,0,0,...}                 // Output array of fixed size N, initialized to zeros

        for i from 0 to N-1 do:
        sum = A[i]
        if i > 0 then:
            sum = sum + A[i-1]      // Add left neighbor if it exists
        if i < N-1 then:
            sum = sum + A[i+1]      // Add right neighbor if it exists
        B[i] = sum / 3              // Each element in B is just the average of the corresponsing element in A and its neighbors
                
        Print Array_A                   // Output the original array
        Print Array_B                   // Output the convolved array

Here are some quick tips, to help you remember how to approach this problem in C:

  • Remember that every program in C needs to have a main function!
  • Remember to specify the datatype of any variable you create!
  • Remember that printing in C requires a bit of setup; also remember to use it to debug!

Part 4: Compiling C Code to RISC-V

Compiling code is the process of taking the higher level code statements you've written (for example, in C), and processing them to create the actual code that will execute on your computer. You've used gcc to do this to make executable files so far, but gcc can also process your code directly into a form of assembly!

Unless you are on RISC architecture (which is unlikely), your code will likely compile to some CISC language, like x86. For this assignment, we want you to compile directly to RISC-V assembly, which can only be done on a RISC-V system (or an emulator!). To get around this, we'll use the Godbolt Compiler Explorer to compile your code to RISC-V assembly.

To do this, place your C code from Part 3 into the left box, and change the language from C++ to C. Next, in the right box, click the dropdown selector on the top, and select "RISC-V (32-bits) gcc (trunk)" from the options. From here, copy the compiled code into your submission document. Look at how the code is structured, and compare it to the RISC-V code you wrote to solve this problem in Project 1.
