Module 4 Lab: Command Line and C Programming

This lab covers the utilization of the following items in RISC-V assembly:

  • Setting up and navigating a command line interface.
  • Compiling and running C code.
  • Understanding how C code compiles to assembly code.

This Lab is still being updated. Feel free to use the Part 1 instructions below to get started on your environment setup, but note that more conceptual questions and activities will be added later.

Lab Description

In this lab, you will be setting up your command line environment and compiling and running C code. You will also be analyzing how C code compiles to assembly, and seeing how real-world assembly code looks.

Part 1: Setting Up Your Environment

Command Line Interface

Windows

Follow all of the installation instructions in the MSYS2 Getting Started Page to install MSYS2 and gcc on your machine.
This will provide a UNIX-like environment where you can run terminal commands that are native to Linux/Mac and compile/run C code.

Note: You may opt to use an alternative environment such as WSL (Windows Subsystem for Linux) if you prefer. You are allowed to do so for the purposes of our class. We encourage you to take ownership, explore your machine, and set up your environment how you see fit. The requirement is that you are ultimately able to compile and run code via the command-line via gcc and can run UNIX instructions.

Please note: Depending on the setup you choose, your files may not be located in your usual system folders; please take time to familiarize yourself with the location of the filesystem you'll be interacting with. By default, the install path for home will be C:\msys64\home\username.

MacOS

For MacOS users, your system already operates using a UNIX environment, meaning you'll be able to perform all commands natively. This only leaves installing gcc, which can be done as follows:

  1. Press Command + Space, search for "Terminal" and hit enter to open your built-in terminal
  2. Go to the brew homepage and copy-paste the command under "Install Homebrew" into your terminal. Hit Enter to run it if it doesn't already automatically.
  3. After Homebrew is installed, you can install gcc using the following command: brew install gcc

Additionally, as we play around with utilizing bash commands, please be wary of your system! Since we'll be doing things on your main system, make sure you keep things clean and organized.

Linux

Congratulations, you are already running in a UNIX-like environment! This means you won't need to go through nearly as much headache to get setup for class. The only step you need to tackle is to install gcc using your distribution's package manager, e.g.:

  • For Ubuntu/Debian: apt install build-essential
  • For Arch: pacman -S gcc

Depending on the configuration of your system, you may need to utilize sudo to actually install the package.

Additionally, as we play around with utilizing bash commands, please be wary of your system! Since we'll be doing things on your main system, make sure you keep things clean and organized.

VS Code Setup

You may install VS Code on your machine using your package manager or by downloading it from the VS Code Download Page.

Alternatively, you can install VSCodium, which is a free and open source fork of VS Code. This means it doesn't have Microsoft additions (such as AI!). It also has fewer tracking components, increasing security and privacy.

MacOS/Linux
