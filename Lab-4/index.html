Module 4 Lab: Command Line and C Programming

This lab covers the utilization of the following items in RISC-V assembly:

  • Setting up and navigating a command line interface.
  • Compiling and running C code.
  • Understanding how C code compiles to Assembly

Lab Description

In this lab, you will be setting up your command line environment and compiling and running C code. You will also be analyzing how C code compiles to assembly, and seeing how real-world assembly code looks.

Submission Format

For this lab, you will submit a single document (Word or .pdf) containing:

  • Screenshots of successfully executed executed CLI instructions
  • Your answers to all conceptual questions, labeled by question number (e.g., "Q2.1.3")

Part 1: Setting Up Your Environment

Command Line Interface

Windows

Follow the installation instructions at the MSYS2 Homepage to install MSYS2 and gcc on your machine. This will provide a UNIX-like environment where you can run terminal commands that are native to Linux/Mac and compile/run C code.

Note: You may opt to use an alternative environment such as WSL (Windows Subsystem for Linux) if you prefer. You are allowed to do so for the purposes of our class. We encourage you to take ownership, explore your machine, and set up your environment how you see fit. The requirement is that you are ultimately able to compile and run code via the command-line via gcc and can run UNIX instructions.
