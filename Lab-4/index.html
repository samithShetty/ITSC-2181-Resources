Part 3: Writing C Code

For this component of the lab, you'll be implementing a program to perform a 1-D convolution on an array of integers.

What is convolution?

Convolution is a special type of computing process and algorithm that works to "smooth" a set of input values out. Convolution is frequently used in areas such as signal and image processing, where we might care about the general data within a signal or an image, but don't want to get hung up on the specifics. This is achieved by creating a new version of the signal, image, or other data, where each value is defined by some "convolution" of how that particular component was defined in the previous bit of data.

A good example of this process is gaussian blurring, which involves allowing one pixel to be averaged with the other pixels around it. If a blue pixel is surrounded by other blue pixels and some red pixels, after convolution, it will be some shade of purple, as the other pixels' colors bleed into it. If we instead imagine a convolution applied to a signal, you might imagine a very high peak surrounded by low areas in the signal; after convolution, the peak is lower, pulled down by the surrounding low areas, while the low areas are pulled up a bit, influenced by the peak. We demonstrate some of these, and the algorithms for doing so, below.

If you would like additional examples or references, check out this intuitive explanation of convolution .

Pseudocode


        A = {[initial array values]}    // Input array of fixed size N, initialized to random values
        B = {0,0,0,...}                 // Output array of fixed size N, initialized to zeros

        for i from 0 to N-1 do:
        sum = A[i]
        if i > 0 then:
            sum = sum + A[i-1]      // Add left neighbor if it exists
        if i < N-1 then:
            sum = sum + A[i+1]      // Add right neighbor if it exists
        B[i] = sum / 3              // Each element in B is just the average of the corresponding element in A and its neighbors
                
        Print Array_A                   // Output the original array
        Print Array_B                   // Output the convolved array

Part 4: Compiling C Code to RISC-V

Compiling code is the process of taking the higher level code statements you've written (for example, in C), and processing them to create the actual code that will execute on your computer. You've used gcc to do this to make executable files so far, but gcc can also process your code directly into a form of assembly!

Unless you are on RISC architecture (which is unlikely), your code will likely compile to some CISC language, like x86. For this assignment, we want you to compile directly to RISC-V assembly, which can only be done on a RISC-V system (or an emulator!). To get around this, we'll use the Godbolt Compiler Explorer to compile your code to RISC-V assembly.

To do this, place your C code from Part 3 into the left box, and change the language from C++ to C. Next, in the right box, click the dropdown selector on the top, and select "RISC-V (32-bits) gcc (trunk)" from the options. From here, copy the compiled code into your submission document. Look at how the code is structured, and compare it to the RISC-V code you wrote to solve this problem in Project 1.
