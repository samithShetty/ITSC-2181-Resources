Project 2: Data Explorer: Building Essential Data Analysis Tools in C - Part 1

This project aims to provide hands-on experience in C programming by implementing essential data analysis tools. The motivation behind the project is to introduce students to both basic and advanced data manipulation techniques, empowering you to solve real-world problems while reinforcing their understanding of programming concepts. Through this project, you will learn how to efficiently work with arrays, perform statistical calculations, and process data using standard algorithms. This project is the first half of building this code base; Project 3 will be the second part of this codebase. Part 1 focuses on implementing an interactive command line program and fundamental array operations, such as finding minimum and maximum values, calculating averages, and counting occurrences of specific elements. Part 2 introduces advanced statistical functions, allowing one to calculate median, mode, range, and standard deviation, while also working with sorting and quartiles.

In Task 1, you will start implementing a command-line interface (CLI) program to allow users to interact with the program by entering commands. You will then implement the basic array operations in C, such as finding the minimum and maximum values, calculating the average, counting occurrences of a specific number, and printing part of the array. The CLI will prompt the user to select a specific operation (command) by entering a number corresponding to the desired function. This will help you gain experience not only in writing basic array manipulation functions but also in working with user input, which is an essential skill in developing interactive programs.

Part 0: Code Setup

To Start: A starting program is given that implements a random generator and includes the function prototypes for forward declaration. You can download the file (using wget command or just copy/paste the content of the file) to start your implementation. The file can be accessed from ITSC_2181-project1-xxx.c.

Part 1: CLI Requirements

To complete this lab, your CLI implementation will need to fit the following general requirements:

  • The program will print a list of available commands, prompting the user to select an option by entering a number.
  • The program will continue to ask for input until the user decides to exit.
  • Each command will correspond to a specific function.

We recommend starting this project by implementing the CLI without any of the functions. Think about what your command line will need to do, and how you'll implement it. You'll need to utilize some type of loop for running the program, and prompt the user for input; you'll then need to check this input to determine what function to run. After running the requested function, it should again prompt for a function to run. This should continue until the user enters something to exit the program.

To see examples of what to implement, please look at the code output example.

Functions to Implement

  1. float findMin(float arr[], int size)
    • Purpose: Finds the minimum value in the array.
    • Return Value: float – the minimum value in the array.
  2. float findMax(float arr[], int size)
    • Purpose: Finds the maximum value in the array.
    • Return Value: float – the maximum value in the array.
  3. float calculateAverage(float arr[], int size)
    • Purpose: Calculates the average (mean) of the array.
    • Return Value: float – the average value of the array.
  4. int findIndexOf(float arr[], int size, float num)
    • Purpose: Finds the index of the first occurrence of a given number in the array.
    • Return Value: int – the index of the number in the array, or -1 if not found.
  5. int countOccurrences(float arr[], int size, float num)
    • Purpose: Counts how many times a given number appears in the array.
    • Return Value: int – the number of occurrences of the specified number.
  6. void printFirst100(float arr[])
    • Purpose: Prints the first 100 elements of the array.
    • Return Value: void – no return value.

Note for comparing float numbers: Comparing two float numbers particularly for equality has been known in computing literally impossible because of rounding errors and the way float numbers are represented in computing. Check Small lesson of the day: never check two floats for equality! In this project, simply subtract two float values from each other, to see if the values received are close enough to each other.

if ( a - b < .0000001 ) { … }
