ITSC 2181 - Introduction to Computer Systems

Learning Objective Conventions

The following conventions should be applied to all learning objectives, to create a consistent and sensible flow of learning for students and instructors:

  1. All learning objectives are framed through the following Bloom's Taxonomy Levels: Knowledge, Understanding, Apply, Analyze, Evaluate, and Create.
  2. All learning objectives of a level higher than Knowledge must have corresponding learning objectives of each level lower.
  3. Lettering is applied from the lowest objective to the highest; A for Knowledge, B for Understanding, etc.
  4. Only the highest level learning objective for a given set of corresponding learning objectives should be student facing, with the following exception:
  5. Apply, Analyze, Evaluate, and Create learning objectives are always student facing.
