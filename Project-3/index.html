Project 3: Data Explorer: Building Essential Data Analysis Tools in C - Part 2

This project aims to provide hands-on experience in C programming by implementing essential data analysis tools. The motivation behind the project is to introduce students to both basic and advanced data manipulation techniques, empowering you to solve real-world problems while reinforcing their understanding of programming concepts. Through this project, you will learn how to efficiently work with arrays, perform statistical calculations, and process data using standard algorithms. This project is the first half of building this code base; Project 3 will be the second part of this codebase. Part 1 focuses on implementing an interactive command line program and fundamental array operations, such as finding minimum and maximum values, calculating averages, and counting occurrences of specific elements. Part 2 introduces advanced statistical functions, allowing one to calculate median, mode, range, and standard deviation, while also working with sorting and quartiles.

For Part 2, you will implement more advanced statistical functions for data analysis by adding functions that calculate the median, mode, range, variance, and standard deviation, as well as sorting the array and calculating quartiles. These statistical functions are essential in many real-world data analysis tasks and will expose you to important concepts like data distribution, dispersion, and central tendency.

Functions to Implement

  1. float calculateMedian(float arr[], int size)
    • Description: This function calculates the median of the array, which is the middle value in a sorted list. If the array size is odd, the median is the middle element. If the size is even, the median is the average of the two middle elements.
    • Steps:
      1. Sort the array. You can implement the sortArray function and use it for this one.
      2. If the size is odd, return the middle element.
      3. If the size is even, return the average of the two middle elements.
  2. float calculateMode(float arr[], int size)
    • Description: The mode is the value that appears most frequently in the array. This function counts how often each value appears and returns the value with the highest frequency. If multiple values have the same frequency, return any of them.
    • Steps:
      1. Use a frequency counting algorithm.
      2. Identify the value that occurs most frequently.
  3. float calculateRange(float arr[], int size)
    • Description: The range is the difference between the maximum and minimum values in the array. This gives a measure of the spread of the data.
    • Steps:
      1. Find the maximum and minimum values using the findMax and findMin functions.
      2. Subtract the minimum from the maximum.
  4. float calculateStandardDeviation(float arr[], int size, float mean)
    • Description: Standard deviation measures how spread out the values are from the mean. It is calculated as the square root of the variance. You can use the sqrt function from math library.
    • Steps:
      1. For each value in the array, compute its squared difference from the mean.
      2. Calculate the variance as the average of these squared differences.
      3. Return the square root of the variance.
  5. float calculateVariance(float arr[], int size, float mean)
    • Description: Variance is a measure of how much the values deviate from the mean. It is the average of the squared differences from the mean.
    • Steps:
      1. Calculate the squared difference between each element and the mean.
      2. Return the average of these squared differences.
  6. void sortArray(float arr[], int size)
    • Description: This function sorts the array in ascending order. Sorting is a prerequisite for calculating the median and quartiles.
    • Steps:
      1. Implement a sorting algorithm (e.g., bubble sort or selection sort).

Note for comparing float numbers: Comparing two float numbers particularly for equality has been known in computing literally impossible because of rounding errors and the way float numbers are represented in computing. Check Small lesson of the day: never check two floats for equality! In this project, simply subtract two float values from each other, to see if the values received are close enough to each other.
